Pages & API Routes

Kiosk UI (/kiosk)

Form: Patient Name, MRN, Mobile, Department (dropdown), Priority (radio)

On Submit → POST /api/tokens → return { tokenNumber, estimatedWait }

Show token and estimated wait, buttons: Print, Send WhatsApp

Staff Dashboard (/staff)

Protected (NextAuth role=“staff”)

Real-time queue table via Socket.io: Token No, Name, Status, IssuedAt, WaitTime

Actions: Call Next (PUT /api/tokens/:id/status), Mark Served, No-Show

Admin Console (/admin)

Protected (role=“admin”)

CRUD Departments & Priority Rules (form modals)

User Management: Invite staff/kiosk/admin via email (NextAuth email link)

Analytics: average wait, throughput, no-show rates (charts via Recharts)

API (/pages/api)

POST /api/tokens → validate/create Patient, create Token, compute estimatedWait = avgServiceTime(dept) * currentQueueLength, emit token.created Socket.io event, send WhatsApp via Twilio, return JSON

PUT /api/tokens/:id/status → update status, timestamps, emit token.called/served/no_show

GET /api/queues?department=code → list issued tokens

POST /api/hms/* stub endpoints to proxy HMS calls (use node-fetch or axios)

GET /api/predict?dept=code → return wait estimate from simple linear model or constant config
