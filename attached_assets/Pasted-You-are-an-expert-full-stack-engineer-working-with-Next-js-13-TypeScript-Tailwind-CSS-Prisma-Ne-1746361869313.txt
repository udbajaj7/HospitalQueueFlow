4. Staff Actions
For the currently active doctor queue:

Next button

If a token is in status Called or Held, its endAt = now().

Update next Issued token to status Called, set its startAt = now(), emit Socket.io event "token.update".

Hold button

Change current token status to Held, leave startAt unchanged.

Do not advance queue.

VIP/Emergency button

Prompt staff to select an existing Issued token or enter a one-off VIP token.

Move that token to top of queue (position 1), update status to Called, set startAt = now().

Reschedule button

Allow drag-and-drop reordering of the Issued tokens in the table.

Persist new position field on Token so the queue order is saved.

5. API Routes & Real-Time

GET /api/staff/unarrived?department=code → returns patients with appointments today but checkInAt == null.
