3. Kiosk Token Issuance Logic

When kiosk user requests a token (walk-in):

Read session.selectedDoctorId or kiosk-selected doctor.

Determine current hour and dayOfWeek.

Verify that the doctor has an availability record covering this hour.

If not available, return HTTP 400 with “Doctor not available now.”

Count today’s booked appointments for that doctor and hour (Token with source=appointment and appointmentTime in this slot).

Count today’s issued walk-ins for that doctor and hour (Token with source=walkin and createdAt in this slot).

If walkInsIssued < walkInSlotsPerHour OR (bookedAppointments < appointmentSlotsPerHour AND walkInsIssued < (appointmentSlotsPerHour – bookedAppointments) + walkInSlotsPerHour), allow issuance.

In other words, let unused appointment capacity overflow to walk-ins.

Otherwise, return HTTP 429 “Walk-in quota full for this hour.”

If allowed, create Token with source = "walkin", assign doctorId, set checkInAt = now(), then existing flow: compute estimatedWait, emit events, and optionally send WhatsApp.

4. Edge Cases & Errors

If appointment no-shows occur (an appointment token not checked in by cut-off time), automatically convert that slot to walk-in capacity at cut-off (e.g., 15 minutes into slot).

If multiple availability ranges overlap or a doctor is double-booked, return a server error and log for admin review.

If time crosses midnight or DST shift, treat each hour strictly by the startHour–endHour semantics.

5. API & Backend Requirements

GET /api/doctors/:id/availability → list of Availability records.

GET /api/doctors/:id/slots?date=YYYY-MM-DD&hour=H → return { bookedAppointments, walkInsIssued, appointmentSlotsPerHour, walkInSlotsPerHour }.

POST /api/kiosk/tokens → implements the kiosk logic above (use source: walkin).

Cron or Scheduled Function /api/appointments/release → runs at each slot’s cut-off to convert no-shows into walk-in slots.

Add unit tests for the slot-quota logic.

6. Frontend Integration

In kiosk form, when doctor is selected, fetch /api/doctors/:id/slots to show live counts and “Walk-in slots left: X” before submitting.

Disable “Get Token” button if slots are full, showing “No walk-in slots available—please try later.”
